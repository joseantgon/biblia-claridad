# Biblia Claridad — versión separada para GitHub

Esta carpeta se generó a partir del HTML entregado el 3 de noviembre de 2026.

## Instalación
Suba **index.html** y la carpeta **assets** a la raíz del repositorio. No suba el ZIP directamente: primero extráigalo. Mantenga los nombres y rutas.

La división preserva el orden de los estilos y scripts originales. Los archivos individuales pesan menos de 25 MB para la carga web de GitHub.

## Límites importantes
Esta versión **no activa** por sí sola el correo, la API de sincronización ni el alojamiento público. El código original incluye dependencias de API que necesitan un servidor HTTPS y configuración segura. No hay claves de Supabase incorporadas.

Antes de publicar o migrar datos, verificar licencias de contenido, credenciales y hacer copias de seguridad. Probar visualización, lectura, búsquedas, audio, planes, favoritos y notas. Para Android WebView con `file://`, usar la versión original hasta adaptar las rutas de recursos y autenticación.
